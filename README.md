# Robotics-Arm-1.0

Robotics-Arm-1.0 is a robotic arm project that I am building from scratch. The 3D designs are complete, and the next step is to bring them to life by printing the parts, assembling the hardware, and writing the code to control the servos.

## Current Progress

### Completed
- Finished the 3D designs of the robotic arm.
- Created the main arm structure and the movable base.
- Exported both designs as STL files for 3D printing.

### Remaining Work
- **Software:** Write the code to control the servo motors.
- **Hardware:** Connect the electronic components and attach the servos to the structure.
- **3D Printing:** Print the designed parts.
- **Testing:** Check the connections, servo movements, and overall working of the arm.

## 3D Files

All the 3D models are available in the `3D Files` folder.

| File | Description |
|---|---|
| `Arms.stl` | Contains the main structure of the robotic arm. |
| `Base.stl` | Contains the base that supports and moves the arm. |

Both files are ready to be used for 3D printing.

## What's Next?

1. Print the 3D models.
2. Attach the servos to the arm.
3. Connect the electronic components.
4. Write the servo control code.
5. Test the arm and fix any issues.

## Project Goal

The goal is to build a working robotic arm using 3D-printed parts, servo motors, and custom code. The project is still in progress, and I'll keep updating this repository as I make progress.
